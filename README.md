🌱 Greenveil Harvest

An open-source cozy farming adventure by Greenveil Studios

Greenveil Harvest is an open-source cozy farming game built with C++ and SFML. Set in a peaceful little village, the game focuses on farming, exploration, progression, and building a life in a welcoming world.

Developed by Greenveil Studios, Greenveil Harvest is now open to everyone. Whether you want to explore the source code, improve existing systems, introduce new mechanics, or build your own version of the game, you're welcome here.

The source code is yours. Help us grow something together.

---

🎮 About the Game

Greenveil Harvest takes place in Greenveil Village, a small world designed to feel alive and inviting.

The game combines cozy farming mechanics with exploration and world simulation. From planting crops to expanding your ranch, there is always something to work on.

Our goal is to create a relaxing experience where players can progress at their own pace.

✨ Features

Some of the systems currently developed include:

- 🌾 Farming – Plant, grow, and harvest crops.
- 🏡 Player Home – Start your journey at Elias's house.
- 🛏️ Sleep System – Rest and continue your adventure.
- 🐄 Ranches – Dedicated areas for ranch-related gameplay.
- 🌳 Procedural World Generation – A generated village environment with natural borders.
- 🛤️ Path Generation – Procedurally generated paths throughout the world.
- 🛒 Greenveil Market – A central location for the game's economy.
- 🤝 Trust System – A foundation for deeper interactions and progression.

Greenveil Harvest is an evolving project. Features and mechanics may change as development continues.

🛠️ Built With

- C++ – Core game programming.
- SFML – Graphics, window management, and multimedia functionality.
